# Changelog

## 0.1.0

- Initial Home Assistant add-on release
- Mumble client with REST API and web UI via ingress ("Open Web UI")
- Configuration via add-on options (server, credentials, mode, crypto, volume, processing, PTT GPIO, web port)
- PulseAudio support (`audio: true`) and optional GPIO chip mapping
- Persistent config/state in `/data`
- Optional MQTT credentials from the Mosquitto add-on
